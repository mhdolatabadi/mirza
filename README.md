# حسابدار

اپ اندروید (Flutter) که پیامک‌های بانکی را می‌خواند، تراکنش‌ها را درمی‌آورد، گزارش ماهانه نشان می‌دهد و خروجی اکسل می‌دهد.

- `packages/bank_sms_parser`: پارسر پیامک (Dart خالص، بدون وابستگی). تست: `cd packages/bank_sms_parser && dart test`
- `lib/services/report.dart`: جمع ماهانه و جمع هر دسته
- `lib/services/categories.dart`: دسته‌بندی خودکار بر اساس کلمه‌های پیامک
- `lib/services/ledger_store.dart`: ذخیره‌ی دسته‌بندی‌های دستی و نام حساب‌ها روی گوشی
- `lib/services/excel_export.dart`: ساخت فایل اکسل (شیت‌های تراکنش‌ها، گزارش ماهانه و دسته‌بندی)
- `lib/services/sms_reader.dart`: گرفتن مجوز، خواندن صندوق پیامک و فیلتر سرشماره‌های بانک
- `lib/services/sheets_sync.dart`: ارسال تراکنش‌های جدید یا تغییرکرده به گوگل شیت
- `lib/services/auto_sync.dart`: ارسال خودکار در پس‌زمینه (WorkManager، حدود هر ۱۵ دقیقه)
- `assets/google_apps_script.gs`: اسکریپتی که داخل گوگل شیت نصب می‌شود

اجرا: `flutter pub get && flutter run` (گوشی اندروید وصل). تست: `flutter test`

قالب‌های پشتیبانی‌شده: بلو، پیامک‌های «مبلغ با علامت + / -» همراه مانده (پایا، حساب‌های نقطه‌دار مثل 10.xxxxxxx.1).
برای اضافه کردن بانک جدید، یک تابع به `_parsers` در `parser.dart` اضافه کنید و نمونه‌ی پیامک را در تست بگذارید.

قالب‌های ناآشنا: اگر در «تنظیمات ← سرشماره‌ی بانک‌ها» فرستنده را انتخاب کنید، پیامک‌هایش بدون خط مانده و با کلمه‌هایی مثل «برداشت ... ریال» هم پذیرفته می‌شوند.

## گوگل شیت

۱. در گوگل شیت: Extensions ← Apps Script، محتوای `assets/google_apps_script.gs` را جای کد پیش‌فرض بگذارید (در اپ دکمه‌ی «کپی کد اسکریپت» هست).
۲. Deploy ← New deployment ← Web app، با Execute as: **Me** و Who has access: **Anyone**.
۳. آدرس Web app را در «تنظیمات ← گوگل شیت» وارد کنید و «ارسال الان» را بزنید.

اسکریپت یک تب «تراکنش‌ها» می‌سازد. هر ردیف ستون «شناسه» دارد، پس ارسال دوباره ردیف تکراری نمی‌سازد و تغییر دسته یا نام حساب همان ردیف را به‌روز می‌کند. اولین گوشی‌ای که به اسکریپت وصل شود رمزش ذخیره می‌شود و درخواست‌های دیگر رد می‌شوند. برای وصل کردن گوشی دیگر، در Apps Script ← Project Settings ← Script Properties مقدار `TOKEN` را پاک کنید.

## CI و APK

هر push به `main` تست‌ها را اجرا می‌کند و یک APK می‌سازد. فایل APK را از صفحه‌ی Actions، داخل اجرای آخر، بخش Artifacts (`hesabdar-apk`) دانلود کنید.
